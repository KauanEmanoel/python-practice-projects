# 📊 Análise Comercial de Vendedores

> Sistema desenvolvido em Python para analisar o desempenho comercial de uma equipe de vendas, acompanhar metas individuais e transformar dados de vendas em indicadores de desempenho.

---

## 🎯 Sobre o projeto

O projeto simula uma análise comercial de uma equipe de vendedores, considerando a quantidade de produtos comercializados, o preço unitário e as metas individuais.

A partir desses dados, o programa calcula o faturamento, identifica os melhores e piores desempenhos e apresenta um relatório com os principais indicadores da equipe.

## 🖥️ Funcionalidades

| Indicador | Descrição |
|---|---|
| 💰 Faturamento individual | Calcula o faturamento de cada vendedor |
| 📈 Faturamento total | Soma o faturamento de toda a equipe |
| 🏆 Melhor vendedor | Identifica o maior faturamento |
| 📉 Pior vendedor | Identifica o menor faturamento |
| 🎯 Acompanhamento de metas | Verifica quem atingiu a meta individual |
| 📊 Percentual de atingimento | Calcula o percentual alcançado da meta |
| 📦 Quantidade vendida | Soma todos os produtos comercializados |
