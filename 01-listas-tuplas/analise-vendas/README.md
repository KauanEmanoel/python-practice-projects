# 📊 Análise de Vendas com Python

## Sobre o projeto

Este projeto consiste em uma aplicação simples desenvolvida em Python para analisar os dados de vendas de uma loja.

O programa percorre uma lista de produtos, calcula o faturamento individual e total, identifica o produto com maior faturamento e contabiliza quantos produtos ultrapassaram R$ 10.000 em faturamento individual por venda e produto.

## Funcionalidades

- Variável de faturamento individual por produto (cálculo).
- Variável do faturamento total da loja (cálculo).
- Variável de Identificação do produto com maior faturamento.
- Variável com acumulador que faz a contagem de produtos com faturamento superior a R$ 10.000.
- Exibição de um relatório organizado no terminal.

## Tecnologias e conceitos utilizados

- Python 3
- Listas e tuplas
- Estruturas de repetição (`for`)
- Estruturas condicionais (`if`)
- Índices
- Acumuladores e contadores

## Exemplo de resultado

```text
========== RELATÓRIO DE VENDAS ==========

Notebook: R$ 35.000,00
Monitor: R$ 18.000,00
Mouse: R$ 3.200,00
Teclado: R$ 3.750,00
Headset: R$ 3.750,00

Faturamento total: R$ 63.700,00
Maior faturamento: Notebook
Produtos acima de R$ 10.000: 5
```

## Objetivo de aprendizagem

Aplicar conceitos fundamentais de Python na resolução de um problema prático de análise de dados, desenvolvendo lógica de programação e familiaridade com estruturas de dados.
