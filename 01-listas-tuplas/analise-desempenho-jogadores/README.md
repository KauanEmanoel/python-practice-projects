# ⚽ Analisador de Desempenho de Jogadores

Projeto desenvolvido em Python para cadastrar jogadores, registrar gols e gerar indicadores de desempenho.

## 🎯 Objetivo

Praticar estruturas de dados e lógica de programação por meio de um sistema simples de análise de desempenho no futebol.

## 🛠️ Tecnologias utilizadas

- Python 3 - Pycharm
- Listas
- Tuplas
- Estruturas de repetição (`while` e `for`)
- Condicionais (`if/else`)
- Acumuladores

## ⚙️ Funcionalidades

- Cadastro de jogadores e quantidade de gols.
- Armazenamento dos dados em listas.
- Conversão dos registros em tuplas.
- Identificação do artilheiro.
- Identificação da menor pontuação.
- Cálculo do total e da média de gols.
- Contagem de jogadores sem gols.

## 📊 Exemplo de resultado

| Indicador | Resultado |
|---|---:|
| Jogadores cadastrados | 4 |
| Total de gols | 16 |
| Média de gols | 4,00 |
| Artilheiro | Carlos (8 gols) |
| Jogadores sem gols | 1 |

## ▶️ Como executar

1. Instale o Python 3.
2. Clone este repositório.
3. Execute o arquivo:

```bash
python main.py
```
